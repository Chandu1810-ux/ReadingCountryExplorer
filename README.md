# ReadingCountryExplorer

A simple Android app with Firebase email and password authentication.

## Features

- Create an account
- Sign in and sign out
- Show the home screen after signing in

## Open the project

Open this folder in Android Studio and let Gradle sync. To use Firebase, configure the Firebase project for your Android app (`com.example.readingcountryexplorer`) and place its `google-services.json` file in the `app/` folder.
